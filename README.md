# 🤖 AI Resume Analyzer

An AI-powered Resume Analyzer that helps users analyze their resumes, calculate ATS scores, identify skills and weaknesses, compare resumes with job descriptions, and get personalized recommendations for improving their resumes.

---

## 🚀 Live Project

🌐 **Frontend:**  
https://ai-resume-analyzer-ochre-five.vercel.app

---

## 📌 About The Project

AI Resume Analyzer is a full-stack web application designed to help job seekers understand how well their resume matches modern recruitment requirements.

The application allows users to upload their resume and receive detailed analysis including:

- ATS Score
- Resume Strengths
- Resume Weaknesses
- Skills Detection
- Missing Skills
- Job Description Matching
- Resume Comparison
- Resume History
- AI-powered Resume Suggestions
- Resume Analytics
- Profile Management
- Notifications
- Google Authentication

The project combines a modern React frontend with a Node.js/Express backend and MongoDB database.

---

## ✨ Features

### 📄 Resume Analysis

Upload your resume and get an automated analysis of its content.

- Resume parsing
- ATS score calculation
- Skills identification
- Resume strengths
- Resume weaknesses
- Improvement suggestions
- Resume summary

### 🎯 ATS Score

The application provides an ATS-style score to help users understand how well their resume is optimized for applicant tracking systems.

### 🧠 AI Resume Analysis

AI-powered analysis provides insights into:

- Resume quality
- Important skills
- Missing skills
- Resume strengths
- Resume weaknesses
- Improvement areas

### 🔍 Job Description Matcher

Paste a job description and compare it with your resume.

The matcher helps identify:

- Matching skills
- Missing skills
- Relevant keywords
- Resume-job compatibility

### 🔄 Resume Comparison

Compare resume information and analyze differences between resumes.

### 📊 Resume Analytics

The analytics dashboard provides a visual overview of resume-related information and analysis results.

### 📚 Resume History

Previously analyzed resumes can be viewed from the Resume History section.

### 🔐 Authentication

The application supports secure user authentication including:

- User registration
- Login
- JWT authentication
- Google authentication

### 👤 Profile Management

Users can manage their profile information from the application.

### 🔔 Notifications

The application provides notification functionality for user-related updates.

### ⚙️ Settings

Users can manage application and account-related settings.
